# Vane

一个不吵的浏览器，而且**它不只是浏览器**——代理是长在它身上的。

不用再装一个 VPN 或代理客户端，也不用在「浏览器」和「翻墙 App」之间来回切：订阅填进来，
网页照常开，该走的走代理、该直连的直连。

**[下载最新版](https://github.com/hhoneypot0-ui/vane/releases)** · Android 8.0+ · arm64 / armv7 各一个包，31 MB

---

## 它和普通浏览器差在哪

普通浏览器只负责打开网页。真要用起来，你还得再装一个代理客户端：注册、导入订阅、
开全局还是分应用、某些 App 还要单独给它开权限，多一层就多一处会出错的地方。

Vane 把这件事收进同一个 App：

- **代理是内置的**，装完就有，订阅链接粘进来或手贴节点都行
- **不用另装代理软件**，也不用设 PAC、填本地端口、配分流规则
- **一份体积、一个入口**：31 MB 里既有浏览器也有代理，少一个常驻 App，少一份内存和电
- 分流三档：规则（国内直连 / 境外走代理）、全局、直连；需要的话整机流量也能接进分流

门槛降在这里：不是所有人都愿意为了看几个网页去研究 Clash 配置。

## 广告拦截也是本地的

规则库随包带着，不联网、不上报：

- 约 **7.8 万条域名规则**（不请求这些域名）
- 约 **1.38 万条元素隐藏规则**（把页面上的广告位直接藏掉）
- 另有 URL 规则与自建规则，可调强度、自检、按站点放行，长按链接就能把某个域名标成广告

## 和 Via 比

骨架是照着 Via 那套极简做的——顶栏一条地址栏、底栏几个键、主页干净。
差别在装完之后能干什么：

| | **Vane** | **Via** |
| --- | --- | --- |
| 体积 | 31–32 MB（代理和规则库都在里面） | 约 2 MB |
| 代理 | **内置**，填订阅就能用，不用另装 VPN | 无，需要另配代理 / VPN App |
| 广告拦截 | 本地 7.8 万域名 + 1.38 万元素规则，强度可调 | 有基础拦截，规则与强度看版本 |
| 隐私空间 | 有：视频 AES-GCM 加密、密码进出、30 秒回锁 | 无 |
| 长截图 | 有，分块拼接不黑屏，超长会提示 | 视版本 |
| 视频 | 主视频嗅探 + 内置播放器（倍速/画中画/手势/下载） | 一般交给系统播放器 |
| 用户脚本 | 支持，`@match`、GM 存储、GM_xmlhttpRequest | 支持 |
| 云同步 | WebDAV，书签历史设置一起走 | 无 |
| 界面自定义 | 118 个可绑定动作，主题可导出分享 | 顶栏底栏等基础配置 |
| 更新 | GitHub Release | 应用市场 |
| 开源 | 是 | 否 |

体积大出来的那 30 MB，基本就是代理核心和规则库——换来的是不用装第二个 App。

## 打开之后能做什么

**标签与导航** — 多标签、切前后、关左关右、恢复刚关掉的；后退前进刷新回顶。

**地址栏** — 敲字就搜，22 个搜索引擎，可自己加模板（`%s` 占位）。

**长按链接** — 就地弹菜单：新标签、复制、下载、丢进内置播放器、交给系统浏览器、把域名当广告处理。

**下载** — 探到 Range 就分片并发，断了能接着下，暂停继续不重来；下载页点一行直接打开，装包直接进安装器。

**长截图 / 嗅探 / 播放器** — 整页拼一张长图；嗅探只挑主视频（按面积、时长、是否在播打分，广告与埋点排除）；
播放器支持 HLS、自动带 Referer、记住倍速、画中画、±10 秒，左右半屏滑调音量亮度。

**读** — 阅读模式抽正文、朗读、存 PDF、离线保存；深色 / 纯黑，深色只走自家样式，不把图片搞成鬼片。

**私密** — 长按地址栏进隐私空间，视频加密存放，离开 30 秒回锁，从这里开的网页不进历史；
加密文件能原样导出备份，但换台机器打不开。

**同步与备份** — WebDAV 同步书签、历史、快捷入口、设置；自动同步只在服务器确实更新时才拉，
撞车了问你「用服务器的 / 保留本机并上传 / 先不动」；也能导成 JSON、书签 HTML 或纯网址清单。

## 安装

1. 到 [Releases](https://github.com/hhoneypot0-ui/vane/releases) 下对应架构的包
2. 点开安装，允许「安装未知应用」
3. 想让它当默认浏览器：设置 › 默认浏览器 › 去系统「默认应用」里选 Vane

## 自己编

```bash
# JDK 17 + Android SDK（compileSdk 37）
./gradlew :app:assembleDebug
```

## 仓库里少了什么

`app/src/main/jniLibs/*/libsingbox.so` 这两个二进制（79 MB + 74 MB）和测试素材没放进来。
浏览器功能不依赖它；要编出能连代理的完整包，把对应 ABI 的文件放回原路径即可。
