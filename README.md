# Vane

一个不吵的浏览器。没有广告，没有统计，不偷偷在后台醒过来。

装完它不会问你要账号，不会给你推「猜你喜欢」，关掉就是关掉了。

**[下载最新版](https://github.com/hhoneypot0-ui/vane/releases)** · Android 8.0+ · arm64 / armv7 各一个包，31 MB

---

## 为什么会有它

主流浏览器这几年越来越像信息流入口：主页塞满推荐，地址栏会联想，通知栏天天叫你回来。
我要的其实很简单——一个能打开网页的东西，顺手、安静、肯让我改。

所以界面抄了 Via 那套极简的骨架，但把手脚都留出来了：底栏几个键、菜单里几项、
长按链接弹什么、上滑下滑干什么，全是数据，改完存在本地，换手机带走。

## 它有什么

**标签与导航** — 多标签、切前后、关左关右、恢复刚关掉的；后退前进刷新回顶，都是常规动作，不花哨。

**地址栏** — 敲字就搜，22 个搜索引擎随便换（也能自己加，一个 `%s` 占位就行）。

**长按链接** — 就地弹出：新标签打开、复制、下载、丢进内置播放器、交给系统浏览器，或者「这个域名以后当广告处理」。

**下载** — 自带下载器，探到服务器支持 Range 就分片并发，断了能接着下，暂停再继续不从头来。
下载页点一行直接打开文件，装包直接进安装器，`✕` 会把断点文件一起清干净。

**长截图** — 整页拼一张，不黑屏也不只截首屏；拼接按实际滚动位置对齐，超长会告诉你截到哪儿。

**嗅探视频** — 只挑这一页的主视频。按显示面积、时长、是否正在播打分，广告位和埋点地址直接排除，
剩下的候选收在「其它 N 个」里，不铺你一屏。

**内置播放器** — HLS 和 mp4 都能放，自动带上 Referer（防盗链的站也能播）；
倍速会记住上次用的，支持画中画、锁屏、±10 秒；右半屏上下滑调音量，左半屏调亮度；看中了直接下载。

**读** — 阅读模式抽正文、朗读网页、整页存成 PDF、离线保存；夜里想看得舒服点，有深色和纯黑。

**私密** — 长按地址栏进隐私空间，视频用 AES-GCM 加密存放（密钥在系统 Keystore 里），
进出要密码，离开 30 秒自动回锁；从这里打开的网页不进历史，也不进会话恢复。
加密文件可以原样导出做备份，但换台机器就打不开了。

**脚本** — 支持用户脚本，`@match` 匹配、GM 存储、GM_xmlhttpRequest 都有，能从 URL 直接装。

**同步与备份** — 填一个 WebDAV 地址，书签、历史、快捷入口和常用设置一起带走。
自动同步只在服务器确实更新时才拉；真撞车了会问你：用服务器的、保留本机并上传、还是先不动。
也能导成 JSON 备份、书签 HTML（Chrome / Edge / Via 都认）或纯网址清单。

**拦截** — 广告规则在本地跑，不联网不上报。强度可调，能自检、能按站点放行、能点选隐藏。

**代理** — 填机场订阅或手贴节点就行；直连、规则、全局三种走法，需要的话整机流量也能接进分流。

**改** — 118 个可绑定动作，按键、手势、菜单项随便换；主题从浅色到纯黑，也能自己调背景色和强调色，
导出成 JSON 发给别人。

## 安装

1. 到 [Releases](https://github.com/hhoneypot0-ui/vane/releases) 下对应架构的包
2. 点开安装，允许「安装未知应用」
3. 想让它当默认浏览器：设置 › 默认浏览器 › 去系统「默认应用」里选 Vane

## 自己编

```bash
# JDK 17 + Android SDK（compileSdk 37）
./gradlew :app:assembleDebug
# 产物 app/build/outputs/apk/debug/app-arm64-v8a-debug.apk
```

## 仓库里少了什么

`app/src/main/jniLibs/*/libsingbox.so` 这两个二进制（79 MB + 74 MB）和测试素材没放进来。
浏览器本身的功能一个都不依赖它；要编出能连代理的完整包，把对应 ABI 的文件放回原路径即可。
