# Vane

> ## 怒砸一亿 Token，DSH 协助开发的这款浏览器，值得吗？

坦白讲：值得的地方和后悔的地方都很具体，先摆出来。

**值的地方**——一个 App 就把「打开网页」和「把路走通」两件事做完。
不用再装第二个客户端，不用教朋友什么叫分流，订阅粘一次就完事；
界面 118 个动作全是数据，改完能导出带走；广告规则、加密存储、AI 调用全在本地，没有账号，没有遥测。

**代价**——装完约占 90–100 MB（代理核心解压就有 79 MB），比 Via 重几十倍；
没有账号体系，同步得自己有 WebDAV；生态小，出问题只能看 GitHub issue。

一亿 Token 买到的不是「又一个浏览器」，是这套东西终于长在同一个进程里。
剩下的，你自己判断值不值。

`1.86.3` · Android 8.0+ · arm64-v8a / armeabi-v7a · APK 31.9 MB · 装后约 90–100 MB

## 它狠在哪

**一、四个 App 的活，一个进程干完。**
浏览器、代理客户端、规则引擎、加密仓库——过去是四个安装包、四套配置、四次排查、四份常驻内存。
这里是一份 31.9 MB 的 APK，一次安装，一个开关，一份订阅。少装三个 App 这件事，本身就是最大的省事。

**二、10 类协议，机场能写的它基本都认。**
`http` / `socks5` / `ss` / `vmess` / `vless` / `trojan` / `hysteria2` / `tuic` / `snell` / `wireguard`。
不止「能连」：REALITY 的 `pbk`/`sid`/`fp`、`flow=xtls-rprx-vision`、`ws`/`grpc`/`h2` 传输、
hysteria2 的 salamander 混淆与 `mport` 端口跳跃、tuic 的拥塞控制与 UDP 中继——参数一个不吞。
机场怎么发链接，这里就怎么吃。

**三、界面不是「能改」，是「交给你」。**
118 个动作可绑：底栏放什么键、菜单有哪些项、长按链接弹什么、上滑下滑干什么。
配色从浅色到纯黑，也能自己调背景与强调色。整套配置是一份 JSON，导出来发给朋友，
他手机上的浏览器立刻长得跟你的一样。别家叫「设置」，这里更像「前端源码」。

**四、拦截在本地，一条请求都不发。**
约 **7.8 万条域名规则** + 约 **1.38 万条元素隐藏规则**，随包分发，本地匹配。
没有云端订阅、没有账号绑定、没有「规则更新请付费」。想更狠就调强度，想放行某个站点就放行，
长按一个链接就能把整个域名标记成广告。

**五、隐私不是开关，是默认路径。**
长按地址栏进隐私空间：视频 **AES-GCM 加密**、密钥交给 Android Keystore、离开 **30 秒自动回锁**。
在这里打开的网页不进历史、不进会话恢复；加密副本能原样导出做备份，但换台机器打不开。
删除要二次确认，删完连解密缓存一起清——不留尾巴。

**六、AI 是你的，不是它的。**
自带接口、自带密钥、自带模型：OpenAI 兼容协议（大多数服务商 + 本地 Ollama / LM Studio）与
Anthropic 原生协议都能接，浏览器里直接总结当前页、就当前页提问。
请求从手机直接发出，不经过任何中转服务器；密钥只落在本机 Prefs。

**顺带还有**：整页长截图按实际滚动位置分块拼接（保底 16000px，超长会告诉你截到哪）；
主视频嗅探按面积/时长/播放状态打分，只给你那一条；
内置播放器带 Referer、记倍速、画中画、半屏手势调音量亮度；
用户脚本支持 `@match` / GM 存储 / 跨域请求；WebDAV 同步只在服务器确实更新时才拉。

## 设计取向

**一、一个 App 就是全部。**
浏览器负责打开网页，代理负责把该走的路走通。这两件事过去要两个程序、两套配置、两次排查；
在这里是同一次安装、同一份订阅、同一个开关。目标很朴素：装完就能用，不需要知道「分流」是什么。

**二、界面即数据。**
底栏放哪几个键、菜单里有哪些项、长按链接弹什么、上滑下滑干什么——全是可序列化的配置，
118 个可绑定动作，导出来就是一份 JSON。换手机带走，发给别人也是同一套。

**三、能力在本地。**
广告规则、代理决策、加密存储、用户脚本全部在设备上跑。没有账号体系，没有遥测。

## 能力

**浏览**
多标签（上限可调）、标签前后切换与批量关闭、恢复刚关掉的标签；页内查找、查看源码、桌面版网站、
字号缩放、隐藏图片省流量、阅读模式（正文抽取）；长按链接就地弹菜单：新标签 / 复制 / 下载 /
内置播放器 / 系统浏览器 / 把域名标成广告。

**搜索**
22 个引擎内置并带联想：Google、Bing、百度、搜狗、360、神马、夸克、头条、Yandex、DuckDuckGo、
Yahoo、Brave、Startpage、Ecosia、维基百科、GitHub、Stack Overflow、MDN、npm、PyPI、arXiv、Google 学术。
长按地址栏即可切换；`%s` 模板可自建任意引擎。

**下载**
先探测 `Range` 支持，再决定分片并发；断点状态落盘，暂停后继续不重下。
下载页点条目直接打开文件，`.apk` 直接交安装器，`✕` 会连同断点文件一起清理。

**媒体**
主视频嗅探按「可见面积 / 时长 / 播放状态」打分，广告与埋点地址直接排除，其余候选收进「其它 N 个」。
内置播放器支持 HLS 与直链 mp4，自动附加 Referer，记住上次倍速，支持画中画、锁屏、±10 秒、
左右半屏滑动调音量与亮度、一键下载。

**阅读与输出**
整页长截图按实际滚动位置分块拼接（不黑屏，超长提示已截到何处）；朗读网页；打印 / 存 PDF；
离线保存与离线页面；深色 / 纯黑主题，深色只走自家样式，不做整页反相。

**隐私空间**
长按地址栏进入，应用内密码或系统验证；视频以 AES-GCM 加密存放，密钥由 Android Keystore 保管，
离开 30 秒回锁；在此打开的网页不进历史、不进会话恢复；加密副本可原样导出备份，也可再收回。

**AI**
接口、密钥、模型都填自己的，不经过任何中转服务器：
- **OpenAI 兼容**（`/chat/completions`）——覆盖大多数服务商，也能接本地 Ollama / LM Studio
- **Anthropic 原生**（`/messages`）——识别 `sk-ant-` 前缀或 anthropic 域名，自动切换协议
- 场景：**总结当前页**、**就当前页提问**（把正文作为上下文，最多 6000 字）
- 密钥只存在本机 `Prefs`，不写日志、不上报

**脚本与同步**
用户脚本支持 `@match`、GM 存储、GM_xmlhttpRequest，可从 URL 直接安装。
WebDAV 同步书签、历史、快捷入口与常用设置；自动同步只在服务器确实更新时拉取，
冲突时提供三种处理方式；导出支持 JSON 备份、书签 HTML、纯网址清单。

**广告拦截**
规则库随包分发，本地匹配：约 7.8 万条域名规则 + 约 1.38 万条元素隐藏规则，另有 URL 规则与自建规则；
强度可调、可自检统计、可按站点放行、可点选隐藏。

## 代理

代理层内置在 App 内，订阅链接或手填节点均可导入，默认「规则」模式：
按 host 判断国内直连、境外按规则转发；亦可切换「全局」或「直连」，并可选择把整机流量接进分流。

| 协议 | 支持情况 | 关键参数 |
| --- | --- | --- |
| `http` / `socks5` | 内置实现，零依赖 | 账号密码、TLS |
| `ss` | 支持 | 多加密方式、插件 |
| `vmess` | 支持 | `ws` / `grpc` / `h2`、`path`、`host`、`tls` |
| `vless` | 支持 | REALITY（`pbk` / `sid` / `fp`）、`flow=xtls-rprx-vision` |
| `trojan` | 支持 | `sni`、`alpn`、传输层同上 |
| `hysteria2` | 支持 | `obfs`(salamander)、`mport` 端口跳跃、`up`/`down` 带宽 |
| `tuic` | 支持 | `congestion_control`、`udp_relay_mode` |
| `snell` | 基础支持 | 版本差异以节点参数为准 |
| `wireguard` | 基础支持 | 密钥、AllowedIPs |
| `ssr` | 暂不支持 | — |

参数写法兼容机场常见的 `sni` / `peer` / `servername`、`allowInsecure`、`skip-cert-verify`、
`type` / `path` / `host` / `serviceName` 等别名。

## 仓库说明

`app/src/main/jniLibs/*/libsingbox.so`（79 MB + 74 MB）与测试素材不入库。
浏览器功能不依赖它；需要完整包时，把对应 ABI 的文件放回原路径即可。
