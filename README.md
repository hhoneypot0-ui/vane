# Vane

一个不吵的浏览器。没有广告，没有统计，不偷偷在后台醒过来。

**[下载最新版](https://github.com/hhoneypot0-ui/vane/releases)** · Android 8.0+ · arm64 / armv7 各一个包，31 MB

---

## 这是什么

界面照着 Via 那套极简做的：顶栏一条地址栏，底栏几个键，主页干净。骨架简单，手脚都留出来了——
底栏放什么键、菜单里有哪些项、长按链接弹什么、上滑下滑干什么，全是数据，改完存在本地。

和普通浏览器比，它多带了两个东西，都在本地跑：

**网络代理**
- 支持导入订阅，或者手填节点
- 直连 / 规则 / 全局三种模式；规则模式下国内直连、境外按规则走
- 代理和浏览器在同一个 App 里，配置一次就够，不用在两个程序之间来回切

**广告拦截**
- 规则库随包带着，不联网、不上报
- 约 **7.8 万条域名规则** + 约 **1.38 万条元素隐藏规则**，另有 URL 规则与自建规则
- 强度可调，能自检统计、按站点放行，长按链接就能把某个域名标成广告

## 和 Via 比

骨架同源（极简、单地址栏、底栏几个键），差别在装完之后能做什么：

| | **Vane** | **Via** |
| --- | --- | --- |
| 体积 | APK 31.9 MB · 装完约 90–100 MB（代理核心解出来占 79 MB） | APK 约 2 MB · 装完约 5 MB |
| 网络代理 | 有，内置，订阅导入 + 规则分流 | 无，需要外部代理客户端 |
| 广告拦截 | 本地 7.8 万域名 + 1.38 万元素规则，强度可调 | 有基础拦截，规则与强度看版本 |
| 隐私空间 | 有：加密存放、密码进出、30 秒回锁 | 无 |
| 长截图 | 分块拼接，不黑屏，超长会提示 | 视版本 |
| 视频 | 主视频嗅探 + 内置播放器 | 一般交给系统播放器 |
| 用户脚本 | 支持，`@match`、GM 存储、跨域请求 | 支持 |
| 云同步 | WebDAV | 无 |
| 界面自定义 | 118 个可绑定动作，主题可导出 | 顶栏底栏等基础配置 |
| 更新 | GitHub Release | 应用市场 |
| 开源 | 是 | 否 |

## 和 Chrome 比

一个日常默认浏览器，一个自己配的浏览器。差别不在「能不能打开网页」，在装完之后多了什么、少了什么：

| | **Vane** | **Chrome** |
| --- | --- | --- |
| 体积 | APK 31.9 MB · 装完约 90–100 MB | APK 约 200–250 MB · 装完通常 400 MB 以上 |
| 账号 | 不需要登录，没有账号体系 | Google 账号，登录后自动同步 |
| 同步 | WebDAV，自己填地址；书签 / 历史 / 设置 | Google 账号同步；可导出书签 HTML |
| 广告拦截 | 本地规则库内置，可调强度 | 无内置；Android 版装不了 uBlock 这类扩展 |
| 用户脚本 | 支持（`@match`、GM 存储、跨域请求） | Android 版不支持扩展 |
| 隐私空间 | 有：加密存放、密码进出、30 秒回锁 | 无；只有无痕模式 |
| 长截图 | 有 | 无 |
| 视频 | 主视频嗅探 + 内置播放器（倍速、画中画、手势） | 网页自带播放器，能力看站点 |
| 自定义 | 118 个动作可绑，主题可导出分享 | 设置项有限，皮肤基本换不了 |
| 统计 | 无 | 有使用统计与遥测（可在设置里关） |
| 代理 | 内置，可订阅 + 分流 | 走系统代理；Android 上不提供应用内分流 |
| 更新 | GitHub Release | Play 商店 |
| 开源 | 是 | 否（Chromium 开源，Chrome 闭源） |

体积这件事说清楚：APK 只有 31.9 MB，但装完实际占约 90–100 MB——代理核心解压后有 79 MB，
这部分是躲不掉的重量。比 Via 重得多，比 Chrome 轻不少；换来的就是不用再装第二个 App。

## 打开之后能做什么

**标签与导航** — 多标签、切前后、关左关右、恢复刚关掉的；后退前进刷新回顶。

**地址栏** — 敲字就搜，22 个搜索引擎，可自己加模板（`%s` 占位）。

**长按链接** — 就地弹菜单：新标签、复制、下载、丢进内置播放器、交给系统浏览器、把域名当广告处理。

**下载** — 探到 Range 就分片并发，断了能接着下，暂停继续不重来；下载页点一行直接打开，装包直接进安装器。

**长截图** — 整页拼一张长图，分块拼接不黑屏，超长会告诉你截到哪儿。

**视频** — 嗅探只挑主视频（按显示面积、时长、是否在播打分，广告与埋点排除）；
播放器支持 HLS、自动带 Referer、记住倍速、画中画、±10 秒，左右半屏滑动调音量亮度。

**读** — 阅读模式抽正文、朗读、存 PDF、离线保存；深色 / 纯黑，深色只走自家样式，不把图片搞成鬼片。

**私密** — 长按地址栏进隐私空间，视频用 AES-GCM 加密存放（密钥在系统 Keystore），
离开 30 秒自动回锁；从这里打开的网页不进历史，也不进会话恢复。
加密文件能原样导出做备份，但换台机器打不开。

**脚本** — 用户脚本，`@match` 匹配、GM 存储、GM_xmlhttpRequest 都有，能从 URL 直接装。

**同步与备份** — 填一个 WebDAV 地址，书签、历史、快捷入口和常用设置一起带走；
自动同步只在服务器确实更新时才拉，撞车了会问你「用服务器的 / 保留本机并上传 / 先不动」。
也能导成 JSON 备份、书签 HTML（Chrome / Edge / Via 都认）或纯网址清单。

**改** — 118 个可绑定动作，按键、手势、菜单项随便换；主题从浅色到纯黑，也能自己调背景色和强调色。

## 安装

1. 到 [Releases](https://github.com/hhoneypot0-ui/vane/releases) 下对应架构的包
2. 点开安装，允许「安装未知应用」
3. 想让它当默认浏览器：设置 › 默认浏览器 › 去系统「默认应用」里选 Vane

## 自己编

```bash
# JDK 17 + Android SDK（compileSdk 37）
./gradlew :app:assembleDebug
```

## 仓库里少了什么

`app/src/main/jniLibs/*/libsingbox.so` 这两个二进制（79 MB + 74 MB）和测试素材没放进来。
浏览器功能不依赖它；需要完整包时，把对应 ABI 的文件放回原路径即可。
