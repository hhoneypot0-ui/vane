## 已备好的候选（随时可落地）

预览图：`docs/logo-preview.png`（也拷了一份到手机 `下载/DSH-Go/vane-名字图标候选.png`）

| 名称 | 图标构成 | 感觉 |
|---|---|---|
| 拂晓 | 地平线 + 半轮日 | 干净、有方向感 |
| 轻舟 | 三角帆 + 弧形船身 | 轻、快、小众 |
| 砚 | 圆角方框 + 一点墨 | 最静、最像工具 |
| 一叶 | 叶形 + 一条叶脉 | 两笔极简，缩放最稳 |
| 拾光 | 三层光弧 + 心点 | 柔和、偏阅读 |
| 星火 | 四角星 | 锐利、有速度感 |

推荐：轻舟 ≥ 拂晓 > 砚 > 一叶 > 星火 > 拾光。
